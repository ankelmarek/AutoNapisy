Syntetyczne próbki testowe wygenerowane z filtra `testsrc2` FFmpeg (256×144, 30 kl./s, jedna sekunda, bez audio).

- `synthetic-hevc.mov`: HEVC, enkoder libx265.
- `synthetic-vp9.webm`: VP9, enkoder libvpx-vp9.

Nie są nagraniami użytkowników ani przykładową transkrypcją. Sprawdzają dekodery dołączonego FFmpeg na Windows, który nie musi zawierać tych enkoderów. Brak zewnętrznych materiałów i dodatkowych licencji do nagrań.
